# Audit perspektiv v humanitních textech

Student zjistí, kde text vydává zkušenost jedné skupiny za obecnou a jak se jeho výklad mění při doplnění doložených perspektiv. Pro VŠ, zejména pro humanitní předměty.

## Jak použít prompt

1. Otevřete [český prompt](cs/audit-perspektiv.md) a vložte jeho obsah jako první zprávu do chatu.
2. Doplňte cílový text s označenými pasážemi nebo stranami, žánr, historický či kulturní kontext a dostupné srovnávací zdroje.
3. Projděte návrh a upravte dokument. Stažitelný DOCX závisí na nástrojích chatu. Náhradní výstup je Markdown pro textový editor.

## Příklad

Porovnej výstavní popisek o původu sbírkového předmětu s katalogem a vyjádřením komunity jeho původu.

## Stav a soukromí

První vydání. Chování v konkrétních modelech ani tvorba příloh zatím nemají doložený test. Repozitář obsahuje textový postup. Podklady zpracovává poskytovatel zvoleného chatu. Používejte veřejné nebo anonymizované materiály.
