# Perspective Audit for Humanities Texts

The student identifies where a text generalises from one group and how documented perspectives change its interpretation. For university humanities work.

## How to use

1. Open the [English prompt](en/perspective-audit.md) and paste it into a new chat.
2. Provide the text with section or page identifiers, genre, historical or cultural context, and any comparative sources.
3. Review the draft and edit the document. Downloadable DOCX depends on the chat's file tools. The fallback is Markdown for a word processor.

## Example

Compare an exhibition label about an object's provenance with the catalogue and a statement from its source community.

## Status and privacy

First release. Model behaviour and file generation have no documented test yet. The repository contains a written workflow. The chosen chat provider handles your materials. Use public or anonymised sources.
